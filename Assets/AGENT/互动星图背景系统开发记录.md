# 互动星图背景系统开发记录

## 目标

在 `Assets/Scenes/SampleScene.unity` 中提供位于战斗和 HUD 后方的互动星图背景：灰色剪影星球缓慢漂浮，点击其附近时触发一次随机方向的扰动，并在平静前避免重复触发。

## 场景结构

`Constellation Background Bootstrap` 是场景中的背景根节点，层级中已保存：

```text
Constellation Background Bootstrap
├── Lines
│   └── Link_XX_XX（固定星图连线）
└── Planets
    └── Planet_01 ... Planet_10
```

- 不再使用旧的 Canvas `BackgroundDecorations`；该节点保持禁用。
- 不再使用 `NodeDot`。
- 星球与连线均为场景内的可见、可直接调整对象；Play Mode 只绑定现有引用，不创建背景对象。
- 排序优先级从低到高为 `BackgroundLines`、`BackgroundPlanets`、默认玩法层，保证背景不遮挡战斗或 UI。

## 运行时行为

- `BackgroundPlanet` 使用 Perlin Noise 作为漂浮目标，并通过弹簧、阻尼、速度上限和最大活动距离维持自然回归。
- `BackgroundTouchInteractor` 只监听鼠标左键按下或触摸按下的当帧；不读取滑动方向、不跟随手指、也不占用 EventSystem 输入。
- 点击落在影响半径内时，星球获得一次随机方向、随机强度的速度冲量。
- 每颗星球必须等待触发冷却结束，且自身速度低于再次触发阈值后，才能接受下一次点击扰动。

## 默认手感参数

| 类别 | 参数 | 默认值 |
| --- | --- | --- |
| 星球运动 | 漂浮半径 / 速度 | `0.8` / `0.6` |
| 星球运动 | 回弹强度 / 阻尼 | `8` / `3.2` |
| 星球运动 | 最大活动距离 / 最大速度 | `0.8` / `8` |
| 点击扰动 | 影响半径 | `3` |
| 点击扰动 | 随机冲量范围 | `3.5–4` |
| 点击扰动 | 冷却 / 再次触发速度阈值 | `0.35` / `0.12` |

## 调试方式

进入 Play Mode 后，`Tools/Debug/Constellation Physics` 会自动打开。窗口通过 `BackgroundPhysicsDebugRuntime` 连接星图运行时，可实时统一调整所有星球的漂浮、回弹、边界和点击扰动参数；退出 Play Mode 自动关闭。

主要代码：

- `Assets/Scripts/Background/BackgroundPlanet.cs`
- `Assets/Scripts/Background/BackgroundTouchInteractor.cs`
- `Assets/Scripts/Background/ConstellationBackgroundBootstrap.cs`
- `Assets/Scripts/Background/BackgroundPhysicsDebugRuntime.cs`
- `Assets/Editor/BackgroundDebug/BackgroundPhysicsDebugWindow.cs`

## 验证要点

1. 星球在无输入时有可见但不过度抢眼的随机漂浮。
2. 点击星球附近后，星球随机弹开而不沿点击/划动方向移动。
3. 星球未冷却或仍在高速运动时，连续点击不会重复触发。
4. 背包拖拽、战斗滑动和 HUD 点击仍正常工作，背景不会阻挡输入。
