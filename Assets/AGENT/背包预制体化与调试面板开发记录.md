# 背包预制体化与调试面板开发记录

## 1. 开发日期

2026-07-22

## 2. 本次目标

将旧的运行时自动生成背包 UI 改造为可在 Unity 编辑器中直接调整的预制体界面，并提供独立背包调试场景和 EditorWindow。

本次不改变背包占用数据的核心规则，不调整现有 DOTween 参数，不与战斗用 `BattleBackpack` 合并。

## 3. 最终规格

- 玩家背包：7 列×4 行，共 28 格。
- 坐标：左上 `(0,0)`，右下 `(6,3)`。
- 装备类别：1×1 正方形、横/竖一字型、四向 L 型。
- 具体变体：7 个。
- 商店：3 个固定槽位，每个槽位独立随机抽取，允许重复。
- 垃圾桶：位于商店右侧。
- 默认背包：固定的 1×1、1×2 和 L 型示例布局。

## 5. Runtime 架构

`BackpackController` 仍是占用数据的唯一可信来源。`BackpackDebugRuntime` 创建 `BackpackController(7, 4)`，并通过 Inspector 引用连接场景已摆放的网格、物品层、拖拽层、垃圾桶和三个商店槽。

运行时只实例化已存在的物品 Prefab，不创建整套 UI 层级。

`ItemView` 继续处理：

- `dragVisualOffset` 和 `grabCellOffset`。
- 黄色/红色放置预览。
- 商店放入背包。
- 背包内移动。
- 垃圾桶删除。
- Hover、Punch 和 Shake 反馈。
- 点击或开始拖拽时请求选中当前物品。

## 6. 调试面板

`BackpackDebugWindow` 位于 `Assets/Editor/BackpackDebug/`，并与 `BackpackDebugWindowLifecycle` 分离。

功能：

- 恢复默认背包。
- 刷新三个商店物品。
- 显示最近选中物品的名称、形状、位置和锚点。
- 垂直显示当前背包物品名称。
- Runtime 准备完成时自动打开，退出 Play Mode 时关闭。

## 7. 旧实现清理

`BackpackPrototypeBootstrap.cs` 和 meta 已删除。工程代码、场景与 Prefab 中不再有对该脚本的引用。
