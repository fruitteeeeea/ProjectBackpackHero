## 1. 系统结构

每个正式物品由三部分组成：

| 部分 | 作用 |
|---|---|
| `ItemData` | 保存物品名称、前景图标、底图颜色、分类、冷却时间和形状 |
| `ItemShapeData` | 保存物品占用的背包格子 |
| 形状 Prefab | 提供形状底图、前景图标层、冷却材质和拖放组件 |

显示时会组合成两层：

```text
具体物品图标（ItemData.Icon）
            ↓
形状底图（形状 Prefab 的根 Image）
```

`ItemData.Background Color` 只改变形状底图颜色，不会改变前景图标。

## 2. 创建新的飞机物品

### 2.1 创建 ItemData

1. 在 Unity 的 `Project` 窗口进入：

   ```text
   Assets/Data/Backpack/Items
   ```

2. 在空白处右键：

   ```text
   Create → Backpack Prototype → Item Data
   ```

3. 使用容易识别的资源名，例如：

   ```text
   Aircraft_Scout
   Aircraft_Bomber
   Aircraft_Interceptor
   ```

资源名推荐使用英文和下划线；游戏内显示名称可以使用中文。

### 2.2 配置飞机

选中新建的资源，在 Inspector 配置：

| 字段 | 填写内容 |
|---|---|
| `Item Name` | 游戏内显示名称，例如“侦察机” |
| `Icon` | 飞机的前景 Sprite |
| `Background Color` | 形状底图颜色，默认 `#FFCC80` |
| `Item Type` | 必须选择 `Aircraft` |
| `Cooldown Duration` | 大于 0 的冷却秒数，例如 `2` |
| `Shape` | 选择一个 `ItemShapeData` |

飞机的冷却时间最小为 `0.01` 秒。选择 `Aircraft` 后如果数值自动变成 `0.01`，再填写需要的正式冷却时间即可。

示例：

```text
Item Name: 侦察机
Item Type: Aircraft
Cooldown Duration: 1.5
Shape: ItemShape_2x1
Background Color: #FFCC80
```

## 3. 创建新的装备物品

### 3.1 创建 ItemData

同样在以下目录创建 `Item Data`：

```text
Assets/Data/Backpack/Items
```

推荐命名：

```text
Equipment_Armor
Equipment_Radar
Equipment_Engine
```

### 3.2 配置装备

| 字段 | 填写内容 |
|---|---|
| `Item Name` | 游戏内显示名称，例如“轻型装甲” |
| `Icon` | 装备的前景 Sprite |
| `Background Color` | 形状底图颜色，默认 `#FFCC80` |
| `Item Type` | 必须选择 `Equipment` |
| `Cooldown Duration` | 自动固定为 `-1` |
| `Equipment Effects` | 可选。拖入装备效果资产；相邻飞机生成时会获得其中的全部效果 |
| `Shape` | 选择一个 `ItemShapeData` |

装备不会进入冷却。尝试修改其 `Cooldown Duration` 后，Unity 会自动将数值恢复为 `-1`。

### 3.3 配置装备子弹

在 `Assets/Data/Backpack/EquipmentEffects` 中右键创建：

```text
Create → Backpack Prototype → Equipment Effects → Projectile
```

为效果配置 `Projectile Prefab` 和 `Cooldown`，再将该效果资产拖入装备的 `Equipment Effects` 列表。多个相邻装备会分别提供效果；同一架飞机的装备子弹会以 0.1 秒共享间隔轮流发射。

示例：

```text
Item Name: 轻型装甲
Item Type: Equipment
Cooldown Duration: -1
Shape: ItemShape_1x1
Background Color: #FFCC80
```

## 4. 选择形状与对应 Prefab

加入物品目录时，`ItemData.Shape` 与目录中的 `Prefab` 必须匹配。

| Shape | 占格 | 对应 Prefab |
|---|---|---|
| `ItemShape_1x1` | 单格 | `Item_1x1.prefab` |
| `ItemShape_1x2` | 纵向两格 | `Item_1x2.prefab` |
| `ItemShape_2x1` | 横向两格 | `Item_2x1.prefab` |
| `ItemShape_L_MissingBottomLeft` | 缺左下角的 L 形 | `Item_L_MissingBottomLeft.prefab` |
| `ItemShape_L_MissingBottomRight` | 缺右下角的 L 形 | `Item_L_MissingBottomRight.prefab` |
| `ItemShape_L_MissingTopLeft` | 缺左上角的 L 形 | `Item_L_MissingTopLeft.prefab` |
| `ItemShape_L_MissingTopRight` | 缺右上角的 L 形 | `Item_L_MissingTopRight.prefab` |

Prefab 目录：

```text
Assets/Prefabs/BackpackUI/Items
```

错误示例：

```text
Data.Shape: ItemShape_2x1
Prefab: Item_1x1.prefab
```

这种配置会造成占格逻辑和显示底图不一致。

## 5. 把物品加入调试商店目录

仅创建 `ItemData` 不会让物品自动出现在商店中，还需要加入场景的 `Item Catalog`。

1. 打开：

   ```text
   Assets/Scenes/BackpackDebugScene.unity
   ```

2. 在 Hierarchy 选中：

   ```text
   BackpackRuntime
   ```

3. 在 Inspector 找到：

   ```text
   Backpack Debug Runtime → Item Catalog
   ```

4. 将 `Size` 增加 1。

   例如原来是 `2`，增加为 `3`。

5. 展开新增的最后一个 Element：

   - `Data`：拖入新建的 `ItemData`。
   - `Prefab`：根据上一节的表格拖入匹配的形状 Prefab。

6. 按 `Command + S` 保存场景。

商店刷新时会从 `Item Catalog` 中随机选择物品。同一个 `ItemData` 在目录中通常只添加一次。

### 多次添加

每制作一个新物品，就继续将 `Item Catalog.Size` 增加 1，并配置新的 Element：

```text
Item Catalog
├── Aircraft_First + Item_2x1
├── Equipment_First + Item_1x1
├── Aircraft_Scout + Item_1x2
├── Equipment_Armor + Item_1x1
└── Equipment_Radar + Item_L_MissingTopRight
```

飞机和装备可以复用相同的 Shape 和 Prefab。具体名称、图标、颜色和冷却来自各自的 `ItemData`。

## 6. 配置默认背包（可选）

如果希望进入 Play Mode 时物品直接出现在背包中：

1. 选中 `BackpackRuntime`。
2. 找到 `Default Placements`。
3. 将 `Size` 增加 1。
4. 在新增 Element 中配置：
   - `Data`：需要默认生成的 `ItemData`。
   - `Anchor Cell`：物品形状的左上锚点。
5. 保存场景。

默认位置必须满足：

- 所有占用格都在 7×4 背包范围内。
- 不与其他默认物品重叠。
- 多格形状需要为右侧或下方占格预留空间。

### 飞机与装备邻接示例

2×1 飞机：

```text
Aircraft anchor: (1, 1)
占据格子: (1,1) (2,1)
```

1×1 装备：

```text
Equipment anchor: (1, 0)
```

布局：

```text
装备  空格
飞机  飞机
```

装备与飞机直接接触，因此飞机能够获得这件装备。

只有上、下、左、右接触才算相邻；对角接触不算。一个多格装备即使同时接触飞机多个格子，也只会被计算一次。

## 7. 验证新物品

### 7.1 基础显示

1. 退出旧 Play Mode。
2. 重新进入 Play Mode。
3. 打开：

   ```text
   Tools → Backpack → Backpack Debug
   ```

4. 点击“刷新商店物品”，直到看到新物品。
5. 确认：
   - 形状底图正确。
   - 前景图标显示在底图中央。
   - 底图颜色与 `Background Color` 一致。
   - 物品占格和 Prefab 形状一致。

### 7.2 飞机验证

选中飞机后确认调试面板显示：

```text
Type: Aircraft
Cooldown: 设置的秒数
```

点击“背包飞机进入冷却”，确认：

- 飞机底图和前景图标同步进入冷却。
- 冷却结束后两层同步闪光。

### 7.3 装备验证

选中装备后确认：

```text
Type: Equipment
Cooldown: Disabled (-1)
```

点击冷却按钮时，装备不应发生冷却变化。

### 7.4 邻接验证

将装备放在飞机四边，选中飞机：

```text
Adjacent Items
装备名称
```

再将装备移动到飞机斜对角或远处，列表中不应继续出现该装备。

## 8. 修改已有物品

修改物品名称、图标、类型、冷却、底图颜色或形状时，应先退出 Play Mode。

### 只修改名称、图标、颜色或冷却

直接编辑 `ItemData` 即可，不需要修改 `Item Catalog`。

### 修改形状

修改 `ItemData.Shape` 后，还必须修改 `Item Catalog` 中该物品对应的 `Prefab`，使二者保持一致。

### 复制已有物品

制作同类物品最快的方式：

1. 选中现有 `ItemData`。
2. 按 `Command + D` 复制。
3. 修改资源名。
4. 修改显示名称、图标、分类、冷却和颜色。
5. 将复制品作为新条目加入 `Item Catalog`。

不要只复制资源却忘记添加目录条目，否则商店不会生成新物品。

## 9. 常见问题

### 物品只显示图标，没有形状底图

检查 `Item Catalog` 使用的是否为正确形状 Prefab，并确认 Prefab 根节点的 Image 仍有 Sprite。

### 物品有底图，没有前景图标

检查：

- `ItemData.Icon` 是否为空。
- 形状 Prefab 的 `ItemView.Icon` 是否引用 `ItemIcon` 子节点。

### 物品显示形状与实际占格不一致

`ItemData.Shape` 和 `Item Catalog.Prefab` 配错。根据第 4 节的表格重新匹配。

### 装备冷却时间无法修改

这是设计行为。装备不冷却，因此系统会把数值固定为 `-1`。

### 飞机无法进入冷却

检查：

- `Item Type` 是否为 `Aircraft`。
- `Cooldown Duration` 是否大于 0。
- 物品是否已经放入背包。

### 新物品不出现在商店

检查：

- 是否加入 `Item Catalog`。
- `Data` 和 `Prefab` 是否都已配置。
- 是否点击了“刷新商店物品”。
- 目录采用随机抽取，条目较多时可能需要刷新多次。

### 默认物品没有生成

检查：

- 是否加入 `Default Placements`。
- `Item Catalog` 中是否存在同一个 `ItemData`。
- 默认位置是否越界或与其他物品重叠。

## 10. 制作检查表

每完成一个新物品，依次确认：

- [ ] 创建并正确命名 `ItemData`
- [ ] 设置显示名称
- [ ] 设置前景图标
- [ ] 设置底图颜色
- [ ] 选择 `Aircraft` 或 `Equipment`
- [ ] 飞机设置正数冷却，装备确认冷却为 `-1`
- [ ] 选择形状
- [ ] 在 `Item Catalog` 中添加条目
- [ ] 选择与形状匹配的 Prefab
- [ ] 如有需要，加入 `Default Placements`
- [ ] 保存场景
- [ ] 重新进入 Play Mode
- [ ] 验证显示、拖放、冷却和邻接
