# Deck 流派平衡说明

五套 Deck 共享给玩家预设和敌方随机池。预设不保存坐标，因此战术提示引导玩家把装备接触正确的飞机；敌人仍使用装备覆盖优先的自动布局。

| Deck | 流派 | 核心 |
| --- | --- | --- |
| 01 | 守线突击 | 护盾拖住战线，冲锋追击，速射补单体。 |
| 02 | 爆破集群 | 双机、爆破和连锁惩罚密集目标。 |
| 03 | 精确处决 | 狙击与激光优先处理远端脆弱目标。 |
| 04 | 贴脸扫荡 | 护盾创造近距离爆发窗口。 |
| 05 | 链接编队 | 链接模块同时覆盖多架飞机，奖励主动布局。 |

数值以 Proposed 为正式默认。Legacy 保留冲锋输出、激光射程与装备伤害的旧值，仅用于开发/测试对照。首轮验收使用同一随机种子，分别测试玩家默认、玩家手动优化、敌人优化三种布局。
