# 关卡流程控制器说明

## 概览

`LevelFlowController` 管理回合编号、横幅显示与背包胜负结算；`BattleFlowController` 仍是准备、过渡和战斗阶段的唯一状态源。

主要文件：

- `Assets/Scripts/Battle/Flow/LevelFlowController.cs`
- `Assets/Scripts/Battle/Flow/LevelFlowBannerView.cs`
- `Assets/Prefabs/UI/LevelFlowBanner.prefab`

## 回合与胜负流程

1. 游戏开始于准备阶段，当前回合为 `Round 1`。
2. 玩家从准备区手动进入战斗时，继续走既有的 `CombatTransition` 动画。
3. 真正进入 `Combat` 后，屏幕顶部层显示 `Round N` 横幅。
4. 战斗中任一背包生命归零时，控制器在该帧结束时统一结算：敌人归零为 `Player Win`，玩家归零为 `Player Lose`；双方同帧归零时判定 `Player Win`。
5. 胜负横幅完整播放后，才切回准备阶段。下一次开始战斗会恢复双方背包生命，并显示下一回合。

## 横幅预制体

`SampleScene` 已放置 `LevelFlowBanner` 预制体。它使用 `Screen Space - Overlay` Canvas，排序值为 1000，因此始终位于所有游戏内容之上，不受场景相机后处理影响。

背景为不引用 Sprite 的纯色方块，水平填满屏幕，高度默认 `128`；文字默认大小为 `64`。

在预制体根节点的 `LevelFlowBannerView` 组件中可以直接调整：

- `Display Duration`：横幅总显示时间，默认 2 秒。
- `Flicker Interval`：闪烁间隔，默认 0.05 秒。
- `Round / Win / Lose Color`：三种横幅背景色。
- `Banner Height`、`Font Size`、`Text Color`：基础视觉样式。

显示和隐藏各有三段闪烁；这些闪烁均包含在 `Display Duration` 总时长中。

## 自动复制敌人背包

`PlayerBackpackDebugBridge` 的 `Auto Copy Player Layout To Enemy` 默认开启。准备阶段中，玩家背包的物品添加、删除、移动、清空或升级后，会自动同步给敌人；同步包含物品、格子位置与等级，不包含冷却状态。该开关也可在 Backpack Debug 的“自动复制开启”勾选框中调整。
