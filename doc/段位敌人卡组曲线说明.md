# 段位敌人卡组曲线说明

段位对战使用 `Assets/Resources/RankDeckPresets` 下的独立 Deck，不是机库的五套共享预设。每个可达阶段都配置三架飞机、两件装备，并按玩家解锁顺序引入新要素。

| 段位 | 核心测试 | 首次出现的机制 |
| --- | --- | --- |
| 1 | 基础站线与弹道 | 先锋、冲锋、护盾、弧线、线圈 |
| 2 | 爆破与单体压力 | 爆破机、速射机炮 |
| 3 | 远程处决 | 狙击、波纹发射器 |
| 4 | 链接与远端选目标 | 激光机、激光链接 |
| 5 | 贴脸爆发 | 需弹、爆炸模块 |
| 6 | 多机编队 | 双机编队 |
| 7 | 流派对抗 | 精确、贴脸、爆破三种高养成组合轮换 |
| 8 | 终局网络 | 仅保留 Lv10 链接编队 |

Rank 8 积分区间只有一分，因此配置为单阶段。解析器按实际阶段数计算，两连败保护在单阶段时不再生成不可达的弱化 Deck。
