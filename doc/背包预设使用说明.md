# 背包预设使用说明

## 预设是什么

背包预设保存 Hanger 的五个 Deck 槽位：前三个是飞机，后两个是装备。它不保存战斗网格坐标；读取时，游戏会按固定的格子扫描顺序找到第一个合法位置，并自动排布到 7×4 背包。

项目已提供五套共用预设：`Assets/Data/Backpack/DeckPresets/DeckPreset_01` 至 `DeckPreset_05`。它们同时用于玩家引导和敌方随机 Deck 池：守线突击、爆破集群、精确处决、贴脸扫荡、链接编队。每套预设都保存一句战术与邻接提示，可在“背包预设”调试页中查看。

## 创建或修改预设

1. 在 Unity 菜单打开 **Tools > Debug > 玩法设计面板**。
2. 点击顶部的 **背包预设** 页。该页不需要进入 Play Mode 就能编辑资产。
3. 在“当前预设”选择已有预设，或点击“新建空白预设”。新资产会保存到 `Assets/Data/Backpack/DeckPresets`。
4. 在“当前配置物品”中逐槽选择物品：飞机 1–3 只能放飞机，装备 1–2 只能放装备；同一物品不能重复使用。留空表示该槽不装物品。
5. 修改会立即写入资产。需要在 Inspector 中查看资产时，点击“选中资产”。

## 从当前玩家 Deck 保存

1. 进入 Play Mode，并确保处于准备阶段。
2. 在背包预设页选择目标预设。
3. 点击“保存当前玩家 Deck 到此预设”，覆盖该预设；或者点击“当前玩家 Deck 另存为新预设”，创建一份新资产。

## 读取预设

1. 在 Hanger 界面时，可直接点击“读取到玩家”；不需要战斗背包或调试桥。
2. 在战斗场景时，保持在准备阶段；战斗阶段为了避免清空冷却和生成队列，读取按钮会禁用。
3. 选择预设，确认“当前配置物品”中的五个槽位。
4. 点击“读取到玩家”：Hanger Deck 会立即替换并保存到本地存档，当前玩家背包也立即重新排布。
5. 点击“读取到敌人”：当前敌人背包使用同一组合重新排布。敌人物品使用默认等级。

页面底部会列出当前玩家和敌人背包中的实际物品与格子位置，方便核对自动排布结果。

## 敌人的正式默认配置

`EnemyBackpack` prefab 的 **Default Deck Preset** 已绑定 `DeckPreset_01`。要让该类敌人默认使用另一套预设：选择 `Assets/Prefabs/Backpacks/EnemyBackpack.prefab`，在 `EnemyBackpackSystem` 组件中替换 **Default Deck Preset**。没有设置该字段的旧敌人会继续读取原有 `EnemyBackpackData`。
